# 리캐치(ReCatch) 진행 상황 · 문제 상황 공유

> 2026-10-28 기준 · 작성: 노현석 (Claude Code와 작업)
> 결제 승인 알림으로 놓친 카드·멤버십 할인을 찾아 2분 안에 재결제하도록 돕는 핀테크 공모전 출품작

## 한눈에 보기

- **된 것:** 기획서 STEP 1(Android 알림 파싱 베타)을 실제로 돌아가는 시제품으로 만들었습니다. 판단 코어 + 백엔드 서버 + Android 앱입니다.
  - 에뮬레이터에서 실제 알림 경로로 끝까지 확인했습니다: 카드 승인 알림 → 추천 알림 → 취소·재결제 → 자동 판정 → 정산.
- **코드 위치:** [SeungbeenYoo/Recatch-APP PR #2](https://github.com/SeungbeenYoo/Recatch-APP/pull/2) (`mvp/` 폴더, 리뷰·머지 대기)
- **가장 큰 문제:** Android 15부터 시스템이 **카드 끝자리 같은 숫자가 든 알림 내용을 가려서** 앱이 못 읽는 경우가 많습니다(아래 문제 1).
- **팀에 부탁할 것:** 실제 카드 승인 문자 샘플, 갤럭시 실기기 테스트, 혜택 약관 확인 ([맨 아래](#팀에-필요한-것))

### 구조

```
[Android 앱] 카드 승인·취소 알림 수집 → 폰 안에서 파싱 (금액·가맹점·카드 끝자리·시각만)
      │  알림 원문·이름은 서버로 보내지 않음
      ▼
[백엔드]     가맹점 정규화 → 혜택 계산 → 재결제 추천 → 취소·재승인으로 자동 판정 → 월 정산
      ▼
[Android 앱] "2,509원 더 아낄 수 있어요" 알림 → 재결제 화면(멤버십 바코드·남은 시간) → 내역·분석·정산
```

### 들어간 기능

- **혜택 계산:** 보유 카드 × 멤버십 조합, 전월 실적, 월 한도(사용액 자동 누적), 시간대, 멤버십 현장할인 + 카드 혜택 중복
- **추천 조건:** 원래 결제보다 1,000원 이상 더 아끼고, 결제 후 2분 안
- **경고:** 원래 카드 실적 미달 위험, 체크카드 환불 지연, 캐시백 확정 대기
- **자동 판정:** 추천 뒤 들어온 취소·재승인 알림으로 완료 / 확인 중 / 놓침 / 취소만 됨 / 이중 결제
- **정산:** 더 아낀 금액의 20%, 첫 달 1,000원 쿠폰, 누적 1만 원 미만은 다음 달로 넘김
- **앱:** 홈·내역·분석·지갑 4화면(좌우 밀기), 정산 명세서, 설정, 지갑 추가(멤버십·카드·통신사), 멤버십 바코드(Code 128·EAN-13, 스캐너 표준 판독 확인), 다크 모드, 재결제 체험

### 확인한 것

- 코어·서버 테스트 44개 통과
- 앱(Java)과 코어(JS) 파서가 샘플 15건에서 같은 결과
- 바코드 9종 표준 판독 확인
- 에뮬레이터: 시연 흐름 전체 + **실제 알림 접근 경로**(adb로 띄운 카드 문자 알림)

### 확정된 결정

- 수수료: **원래 결제 대비 추가로 아낀 차액의 20%** (전체 혜택의 20% 아님)
- 웹 시연(index.html) 숫자는 각자 따로 반영

## 2. 문제 상황

### 문제 1. Android 15가 카드 알림 내용을 가림 (가장 중요)

Android 15부터 시스템이 **인증번호(OTP)가 든 것으로 판단한 알림은 일반 앱에게 내용을 가려서** 넘깁니다. 리캐치가 받는 것은 `Sensitive notification content hidden`뿐이라 아무것도 처리할 수 없습니다.

에뮬레이터(Android 15)에서 시험한 결과입니다.

| 알림 내용 | 결과 |
| --- | --- |
| `현대카드 승인 김*캐 13,000원 일시불 10/28 13:32 스타벅스영남대정` | 정상 |
| 같은 문장에 130,000원·1,250,000원 | 정상 |
| `현대카드(5530)승인 …` (괄호 속 카드 끝자리) | **가려짐** |
| 알림 제목이 발신번호 `15776200` | **가려짐** |
| `… 누적350,000원` | **가려짐** (`누적35,000원`은 정상) |
| `인증번호 [482913]` | 가려짐 (원래 대상) |

- **영향:** 실제 카드 문자는 대부분 `KB국민체크(9421)`처럼 끝자리가 들어 있고, 문자앱 알림 제목은 발신번호인 경우가 많습니다. **Android 15 이상 폰에서는 상당수 카드 문자를 못 읽을 수 있습니다.**
- **피할 수 없음:** 예외 권한은 시스템 앱·워치 연동 앱 같은 특정 역할만 받을 수 있습니다.
- **모르는 것:** 삼성 One UI도 같은지 자료를 못 찾았습니다(국내 사용자 대부분이 갤럭시). Android 16은 와이파이가 아니거나 최근 잠금 해제하지 않은 상황에서만 가린다는 보도가 있습니다.
- **대응 후보:** 문자 권한(READ_SMS)을 보조로 붙이기. 문자 권한은 이 가림의 영향을 받지 않습니다. 구글 플레이에 **"SMS 기반 자금 관리"** 예외가 있지만, 신고서 제출과 심사 승인이 필요합니다. 이번 가림 문제가 "알림 접근으로는 안 된다(대안 없음)"는 신청 근거가 됩니다.
- **필요한 것:** 갤럭시(Android 15·16) 실기기에서 실제 카드 문자로 확인

### 문제 2. 지금 상태로는 플레이스토어에 못 올림

앱 종류 자체는 올릴 수 있습니다. 하지만 다음을 고쳐야 합니다.

| # | 문제 | 해야 할 일 |
| --- | --- | --- |
| 1 | 대상 Android 버전이 API 35 (2026-08-31부터 새 앱은 API 36 이상 필수) | API 36으로 올리고 Android 16 동작 확인 |
| 2 | 서버 주소를 사용자가 직접 입력, PC 서버·HTTP 평문 통신 | 공개 HTTPS 서버, 주소 고정 |
| 3 | 계정 삭제 기능 없음 (계정을 만드는 앱은 앱 안 + 웹 삭제 경로 필수) | 서버·앱에 계정·데이터 삭제 추가 |
| 4 | 개인정보처리방침 없음 | 처리방침 페이지, 데이터 보안 항목 작성 |
| 5 | 디버그 빌드뿐 | 서명된 AAB 빌드 |
| 6 | 패키지명 `kr.recatch.proto`(한 번 올리면 못 바꿈), 이름 "리캐치 시제품", 기본 아이콘 | 이름·아이콘 확정 |

- **개인 개발자 계정이면** 출시 전에 12명 이상 × 14일 연속 비공개 테스트가 필요합니다. 대학가 파일럿(STEP 2)을 이걸로 하면 됩니다.
- **결제 정책 위험:** 성공 수수료와 프리미엄 구독은 앱 안 디지털 서비스로 볼 가능성이 큽니다. 그러면 구글 결제나 한국용 대체 결제를 써야 하고, 기획서대로 PG 직접 청구는 정책 위반이 될 수 있습니다. **결제를 붙이기 전에 정책 확인이 필요합니다.**

### 문제 3. 데이터가 전부 예시

- 카드·멤버십 혜택 값은 웹 시연과 같은 **예시**입니다(`verified: false`). 실제 약관 확인 전입니다.
- 승인 문자 형식은 **추정**입니다. 실제 카드사별 문자로 보정해야 합니다.
- 가맹점 사전에 없는 가맹점은 추천하지 않습니다. 영남대 상권 가맹점명을 실제 문자에 찍히는 대로 넣어야 합니다.

### 문제 4. 서버 구조는 파일럿까지만

실측(이 PC, Node 1개): 사용자 1명당 메모리 약 4KB에서 시작해 **한 달에 22KB씩** 늘어납니다. 처리량은 초당 약 320건입니다.

- **~500명 파일럿:** 지금 구조로 최소 사양 서버 1대(1 vCPU / 1GB)면 됩니다.
- **그 이상:** 저장할 때마다 DB 전체를 JSON 파일로 다시 쓰는 구조라, 2,000명×3개월(100MB)이면 저장 한 번에 0.5초씩 멈춥니다. DB로 바꿔야 합니다.
- **실제 부하는 앱 새로고침:** 앱이 켜져 있는 동안 5초마다 요청 3개를 보냅니다. 결제 알림보다 30~40배 많아서 줄여야 합니다.

### 문제 5. 아직 없는 기능

- 실제 결제 청구(PG·구글 결제), 프리미엄 구독 가입·해지
- 계정(폰 바꾸면 기록 복구 불가), 동의 철회 시 서버 데이터 삭제
- 실증 지표 관리자 화면, 잘못된 추천 신고 버튼
- 마이데이터 연동, iOS, 가맹점 POS 연계, 카드사 B2B 리포트
- 친구 초대 혜택, 영남대 거점 지도(현장 검증 전)

### 기타

- 앱의 문자 읽기 규칙에 알려진 약점이 있습니다.
  - "취소"라는 말이 들어간 승인 문자를 취소로 볼 수 있습니다.
  - "신한"만으로 카드사를 판단해서, 신한은행 알림을 카드로 볼 수 있습니다.
  - 해외 결제·부분 취소는 다루지 않습니다.
- Android 13 이상에서 APK를 직접 설치하면 알림 접근이 막힙니다(설정 → 앱 → ⋮ → 제한된 설정 허용 필요). 플레이 비공개 테스트로 배포하면 사라집니다.

## 팀에 필요한 것

1. **실제 카드 승인·취소 문자 샘플:** 갖고 있는 카드사별로 받아 주세요. 문자, 카드사 앱 푸시, 카톡 알림톡 모두 필요합니다. 이름·전체 카드번호는 가려 주세요. 형식 보정과 테스트에 바로 씁니다.
2. **갤럭시 실기기 테스트:** Android 15·16 폰에 APK를 깔고 실제 결제 알림이 읽히는지 확인합니다(문제 1).
3. **혜택 약관 확인:** 영남대 상권 가맹점과 대학생이 많이 쓰는 카드·통신사 멤버십 혜택입니다. 약관 URL과 확인 날짜도 함께 남겨 주세요.
4. **정할 것**
   - 문자 권한(READ_SMS) 보조를 붙일지 (플레이 신고서 필요)
   - 정식 앱 프레임워크 (React Native + Kotlin 권장 vs 지금 Java 유지)
   - 캐시백·청구할인 확정 방식 (사용자 확인 vs 기간 지나면 자동)
   - 결제 방식 (구글 결제 / 한국 대체 결제 / PG) — 정책 확인 후
   - 플레이 개발자 계정 종류 (개인 vs 사업자)
5. **PR #2 리뷰·머지:** [SeungbeenYoo/Recatch-APP#2](https://github.com/SeungbeenYoo/Recatch-APP/pull/2)

## 직접 돌려 보기

PR #2 브랜치의 `mvp/README.md`에 자세히 있습니다.

```sh
cd mvp
npm test        # 테스트 44개
npm start       # 백엔드 서버 (포트 8787)
```

Android 앱 빌드는 `mvp\android\build.cmd`(Windows) 또는 `mvp/android/build.sh`로 합니다. 앱 설정에서 서버 주소를 넣으면 연결됩니다(같은 Wi-Fi에서는 PC 주소, 에뮬레이터에서는 `http://10.0.2.2:8787`).
